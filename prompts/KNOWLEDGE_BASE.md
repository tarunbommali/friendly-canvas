# SWE Notebook: Complete Master Knowledge Base for AI Prompt Generation

## 1. Executive Summary & Brand Purpose
**SWE Notebook: Zero to Hero** is a multi-track visual curriculum (Tracks 1 to 21) teaching computer science, software engineering, systems design, and AI agents through high-retention, publication-grade Instagram carousels.

Every post is an educational storyboard composed of 7 vertical (4:5) slides designed with Swiss editorial typography, tactile paper textures, track-specific color harmonies, and structured information layouts.

---

## 2. Visual DNA & Design Foundations

### 2.1 Dimensions & Framing
- **Aspect Ratio**: 4:5 Vertical Portrait (`1080 x 1350 px`).
- **Safe Zone**: 96px top buffer (avoids platform UI), 112px bottom buffer.
- **Canvas Base**: `#F8F7F4` (tactile fine paper grain) or crisp `#FFFFFF` studio card.
- **Chrome**: Top-left monospace track badge `[ T{TT} · {Palette} ]`, bottom-left `0{S}/07`, bottom-right `Swipe ➔` (omitted on Slide 7).

### 2.2 Typography
- **Headlines**: Sora / Poppins Bold / Editorial Serif (`48px-58px`) with fluorescent accent highlighter boxes.
- **Body & Insights**: Inter / Satoshi Medium (`24px-30px`) inside structured container cards.
- **Tags & Metadata**: JetBrains Mono SemiBold (`16px-20px`).

## 3. The 7-Slide Carousel Rhythm & Layout Variations

To maximize retention and engagement, each slide position follows a distinct visual LayoutCategory:

| Slide # | Canonical Role | LayoutCategory | Visual Structure |
| :---: | :--- | :--- | :--- |
| **1** | Hook / Scroll-Stopper | `hook-open` | Asymmetric Big-Type headline with fluorescent highlighter box & topic watermark. |
| **2** | Core Concept Breakdown | `concept-explain` | Split container: top vector diagram/icon card + bottom structured takeaway text. |
| **3** | Multi-Step Mechanism | `process-flow` | 3-stage sequential directional pipeline with numbered badge pills (01, 02, 03). |
| **4** | Trade-off / Contrast | `comparison` | Dual-column 50/50 split card: "Without/Legacy (✗)" vs "With/Modern (✓)". |
| **5** | Real-World Application | `concept-explain` | Dark-mode IDE/terminal window (`#1E1E2E`) with code or system blueprint. |
| **6** | Scannable Summary | `recap-close` | 4-point bulleted checklist card with circular checkmark tick icons (`✓`). |
| **7** | Series Finale / Next Up | `closing-cta` | Official SWE Notebook circular brand seal + Next Post preview card + Save/Follow CTA. |

## 5. Visual Glossary of Standard Technical Icons
- **CPU**: Square silicon chip with pin connectors on 4 sides and glowing circuit tracks.
- **Memory/RAM**: Stacked horizontal memory address bars with hex register cells.
- **Client/Server**: Device node (laptop) connected via packet wire to server rack.
- **Database**: 3-tier cylinder icon with data layers.
- **Model (AI)**: Rounded chip with glowing synaptic neural graph nodes.
- **Agent**: AI brain node with tool loop arrows, memory cylinder, and sensor.
