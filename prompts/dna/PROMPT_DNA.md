# SWE Notebook — Prompt DNA & Generation Formula

## 1. The 5-Part Master Prompt Formula

Every slide prompt generated by our system follows a calibrated 5-part architecture to ensure consistent rendering across Midjourney, DALL-E 3, Gemini ImageFX, and Stable Diffusion:

```
[1. Canvas & Format Specification] +
[2. Track Color Theme & Palette Binding] +
[3. LayoutCategory & Structural Geometry] +
[4. Headline & Core Content Payload] +
[5. Card Chrome, Vector Directives & Quality Modifiers]
```

---

## 2. Component Token Breakdown

### Part 1: Canvas & Format
```
An ultra-clean, high-retention 4:5 vertical editorial carousel slide for Instagram (1080x1350 px, portrait orientation).
```

### Part 2: Track & Color Binding
```
Series: SWE Notebook (Zero to Hero) | Track: "${TrackName}" (${PaletteName} palette: Primary ${primaryHex}, Accent ${accentHex}).
Canvas & Texture: ${BackgroundDescription} (tactile off-white paper texture #F8F7F4, 20px technical dot-grid).
```

### Part 3: LayoutCategory Binding
```
LayoutCategory: ${LayoutCategoryName} (${LayoutCategoryStructuralDescription})
Visual Hierarchy: ${EyeFlowPattern} (e.g., Z-pattern top-to-bottom).
```

### Part 4: Content & Typography Payload
```
Headline: "${SlideTitle}" rendered in bold, high-contrast Editorial Serif/Sans typography with fluorescent ${accentHex} highlighter box accent.
Content: "${Content}" in clean modern Inter typography inside a structured frosted white card container with soft 12px border radius.
```

### Part 5: Visual Directive & Chrome
```
Visual Directive: ${VisualDirective}
Card Chrome:
- Top-Left: Monospace track identifier "T${TrackNo}".
- Bottom-Left: Slide counter "${SlideNo} / ${TotalSlides}".
- Bottom-Right: Minimalist "Swipe ➔" navigation cue.
Aesthetic Rules: High-contrast technical editorial, vector line art, clean negative space, 8k resolution, crisp vector graphics, no cluttered 3D realism, no blurry low-res artifacts.
```

---

## 3. Negative Prompt & Exclusion Tokens

When targeting Stable Diffusion or midjourney parameterization, append:

```
--no 3d clipart, blurry text, cluttered icons, photorealistic faces, messy gradients, watermark logos, distorted frames, low resolution, artifacts, dark gloomy backgrounds
```

---

## 4. Lighting & Texture Tokens
- `Tactile paper texture`: Fine fibrous grain (#F8F7F4) giving a notebook / editorial feel.
- `Soft diffuse ambient studio lighting`: Clean highlights without harsh specular glare.
- `Vector line art with 2px uniform stroke`: Clean engineering diagrams.
- `Fluorescent marker accent`: Soft colored box behind keyword headers.
