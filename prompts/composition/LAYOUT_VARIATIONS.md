# SWE Notebook — Slide Layout Variations Across Carousel Flow

## 1. The Carousel Rhythm Rule
A high-retention technical Instagram carousel must **never look repetitive**. Consecutive slides must shift visual density, card arrangements, and eye scan paths while keeping brand DNA 100% consistent.

---

## 2. 7-Slide Sequential Layout Structure

### Slide 1: The Hook / Scroll-Stopper (`hook-open`)
- **Layout Style**: *Asymmetric Big-Type Hero*.
- **Visual Composition**:
  - Top 15%: Subtle track badge `[ TRACK 01 · SEPIA ]`.
  - Center 65%: Massive bold 54px headline with fluorescent accent highlighter block behind punchy keywords.
  - Bottom 20%: Faint technical watermark silhouette (e.g. vintage abacus or schematic) + clean `Swipe ➔` cue.
- **Eye Flow**: Central punch -> downward hook.

### Slide 2: Core Concept Breakdown (`concept-explain`)
- **Layout Style**: *Split Container (Top Visual / Bottom Explanation)*.
- **Visual Composition**:
  - Top 50%: Clean framed technical diagram/icon card with soft 1.5px border and accent-tinted background.
  - Bottom 50%: Crisp headline + 2-sentence key insight card with bold key terms.
- **Eye Flow**: Top diagram recognition -> bottom takeaway reading.

### Slide 3: Multi-Node Workflow / Progression (`process-flow`)
- **Layout Style**: *Directional Stepper (Horizontal or 3-Row Vertical Pipeline)*.
- **Visual Composition**:
  - Top 20%: Short concept premise headline.
  - Middle 65%: 3 sequential rounded pill nodes linked by directional chevron arrows (`Step 1` ➔ `Step 2` ➔ `Step 3`), each featuring a micro-icon and 4-word label.
  - Bottom 15%: Summary footer card.
- **Eye Flow**: Left-to-right or top-to-bottom sequential traversal.

### Slide 4: Contrast & Trade-off (`comparison`)
- **Layout Style**: *Dual-Column Split (Before vs After / Old vs New / Pattern A vs B)*.
- **Visual Composition**:
  - Left Column (50%): Dimmed neutral background, "Without / Old Way" card with subtle red/muted border and cross icon.
  - Right Column (50%): Bright accent-tinted background, "With / New Way" card with track primary border and checkmark icon.
- **Eye Flow**: Left-to-right comparative evaluation.

### Slide 5: Production / Real-World Application (`concept-explain` / `process-flow`)
- **Layout Style**: *Terminal / Production Scenario Card*.
- **Visual Composition**:
  - Top 25%: "Real-World Engineering Scenario" badge + context headline.
  - Center 60%: Dark-mode syntax-highlighted code block / terminal window or architectural interaction blueprint.
  - Bottom 15%: "Why this matters in production" tip callout.
- **Eye Flow**: Code/terminal focal point -> bottom practical takeaway.

### Slide 6: Scannable Summary Checklist (`recap-close`)
- **Layout Style**: *4-Point Checklist Card*.
- **Visual Composition**:
  - Top 20%: "Quick Recap" headline with track badge.
  - Center 70%: 3-4 structured bullet items inside crisp white cards with circular tick icons (`✓`) in track primary color.
  - Bottom 10%: Key takeaway highlighter pill.
- **Eye Flow**: Vertical top-to-bottom rapid scan.

### Slide 7: Series Finale & Next Up CTA (`recap-close`)
- **Layout Style**: *Official Brand Seal & Next Chapter Card*.
- **Visual Composition**:
  - Top 35%: Official SWE Notebook circular vector brand seal badge (`SWE Notebook · Zero to Hero`).
  - Center 45%: Elevated card previewing the Next Post title and track number.
  - Bottom 20%: Prominent save post (`🔖 Save for later`) & follow CTA button.
- **Eye Flow**: Central brand authority -> upcoming topic anticipation -> CTA engagement.
