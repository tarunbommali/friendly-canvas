# SWE Notebook — Style Guide & Visual Elements

## 1. UI Components & Visual Micro-Assets

### 1.1 Fluorescent Highlighter Marker
- **Usage**: Used behind high-impact headline keywords and critical terminology.
- **Form**: Rounded rectangle with `4px` padding extending beyond text, opacity `100%`, rendered in the track's Accent color (`#HEX`).
- **Effect**: Replicates a vibrant highlighter pen swipe over paper.

### 1.2 Monospace Code Tags & Badges
- **Font**: JetBrains Mono or Space Grotesk.
- **Structure**: `[ T01 · Sepia ]`, `[ POST 04 ]`, `[ LayoutCategory: FLOW ]`.
- **Background**: Soft neutral gray `#F3F4F6` or 15% opacity primary tone.
- **Border**: `1px solid rgba(0, 0, 0, 0.1)`.

### 1.3 Dark-Mode Terminal Window (Slide 5 Real-World Moments)
- **Header**: Mac-style window controls (3 dots: Red `#FF5F56`, Yellow `#FFBD2E`, Green `#27C93F`).
- **Background**: Deep Slate `#1E1E2E` or Charcoal `#181825`.
- **Code Typography**: JetBrains Mono, 16px, with vibrant syntax highlighting.
- **Shadow**: `0 12px 36px rgba(0, 0, 0, 0.25)`.

### 1.4 Directional Micro-Arrows
- **Chevron Style**: `➔` or `──►` with clean 2px uniform vector stroke.
- **Usage**: Connects process pipeline nodes and anchors the bottom-right `Swipe ➔` cue.

### 1.5 Official SWE Notebook Brand Seal
- **Outer Ring**: Concentric vector circle with `1.5px` stroke and star bullet points.
- **Text Ring**: `* ZERO TO HERO * SOFTWARE ENGINEERING NOTEBOOK *`.
- **Inner Core**: Bold serif `SWE` centered over a highlighter block with cursive/italic `notebook` in navy blue pen style underneath.
