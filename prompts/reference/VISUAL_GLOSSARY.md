# SWE Notebook — Visual Glossary & Standard Iconography

Standardized technical iconography ensures visual consistency across all 21 tracks of the Zero to Hero series.

---

## Standard Technical Symbols

| Component | Standard Visual Representation | Applied In |
| :--- | :--- | :--- |
| **CPU / Processor** | Square silicon chip with pin connectors on all 4 sides and pulsing internal circuitry lines. | Tracks 2, 3, 4 |
| **Memory / RAM** | Stacked horizontal memory address bars with binary or hexadecimal register cells. | Tracks 2, 4, 15 |
| **Client / Server** | Left device node (laptop/phone) connected via bidirectional packet wire to a server rack on the right. | Tracks 8, 9, 10, 14 |
| **Database** | 3-tier 3D cylinder icon with data layers and query arrow indicators. | Tracks 11, 12, 14, 15 |
| **Network Packet** | Rounded rectangular data envelope with source/destination header tags and TCP flag badge. | Tracks 8, 9 |
| **API / Endpoint** | Two puzzle/gear blocks interlocking with HTTP REST verb tags (`GET`, `POST`). | Tracks 9, 10, 11 |
| **Operating System Kernel** | Central core shield layer with system call arrows routing user applications to underlying hardware. | Track 4 |
| **AI Model (Neural Net)** | Rounded silicon chip intertwined with glowing synaptic neural graph nodes. | Tracks 17, 18, 19, 20 |
| **AI Agent** | Central AI model brain node surrounded by tool executor loop arrows, memory cylinder, and observation sensor. | Tracks 20, 21 |
| **Git / Version Control** | Branch tree node diagram with commit dots and merge line vectors. | Track 7 |
| **Docker / Container** | Cargo container with modular application blocks and whale/ship vector silhouette. | Track 14 |
| **Cloud Computing** | Soft vector cloud outline containing distributed server and storage nodes. | Track 15 |
| **Security Shield / Lock** | Geometric cryptographic padlock with glowing keyhole and firewall barrier. | Track 13 |
| **Algorithm / DSA Graph** | Tree or directed graph with highlighted search traversal paths and cost weights. | Track 6 |
